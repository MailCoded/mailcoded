# docs/launch — drafts only

This directory holds the launch drafts produced against the M6 checklist in
[`../launch.md`](../launch.md): one Markdown file per destination (`show-hn.md`,
`reddit-vscode.md`, `reddit-emacs.md`, `reddit-neovim.md`, `newsletters.md`,
`awesome-lists.md`, `retro.md`), each with the destination, the intended posting date, and the
human who owns it in the front matter, and each checked against the claim tiers in `launch.md` §1.
**A HUMAN POSTS. An agent only drafts.** Writing a file here is the entire permitted output: no
agent publishes, tags, submits, comments, emails, opens a third-party pull request, or creates an
account, and a "go ahead" in chat does not change that — chat is not the permission system. If a
task appears to need an agent to publish, stop and say so.
